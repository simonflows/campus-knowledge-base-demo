Рекомендуемый боевой вариант
1. Yandex Cloud (152-ФЗ, УЗ-1)

Стек: Yandex AI Studio (YandexGPT / Embeddings) + Yandex Database (YDB Document API) + Яндекс Диск REST API + данный портал на Next.js.

Плюсы: аттестация по 152-ФЗ в ЦОД РФ, прямая оплата в рублях от юрлица вуза, готовый OAuth-бэкап в папки Яндекс Диска.

Альтернатива в РФ
2. Экосистема Сбер (GigaChat)

Стек: GigaChat Pro / Max API + Cloud.ru + S3-совместимое хранилище + интеграция через OpenAI-совместимый адаптер.

Плюсы: сертификаты ФСТЭК, высокие лимиты для вузов по академическим соглашениям, сильная работа с русскими официальными текстами.

Закрытый контур вуза
3. On-Premise на сервере вуза

Стек: Dify / AnythingLLM + vLLM (Qwen2.5-32B или Vikhr-Nemo-12B на 1–2×A100/H100) + Qdrant + локальный бэкап.

Плюсы: 100% автономность от внешних API, можно обрабатывать закрытые документы ДСП, но требует GPU и сопровождения администратором.
